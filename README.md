# 🌿 duanwu-egg-balancing (端午立蛋平衡挑戰)

這是一款專為端午節活動設計的 **AI 體感互動網頁遊戲**。免安裝任何硬體與 APP，只需打開瀏覽器與視訊鏡頭，即可透過 Google MediaPipe Pose 科技進行「開眼單足立」的平衡挑戰，結合傳統立蛋習俗與現代體適能檢測。

---

## 🎮 遊戲核心玩法

1. **遊玩前準備**：玩家退後讓全身入鏡，現場主持人引導確認環境安全（旁有牆壁可扶）。
2. **觸發起點**：玩家將非慣用腳抬起，**將腳踝貼在支撐腳的「膝蓋與腳踝中點」**，系統將自動無縫啟動計時。
3. **動態平衡**：畫面的雞蛋會隨玩家身體晃動實時傾斜。偏離中心太多會觸發「劇烈搖晃」紅光警告。
4. **淘汰條件**：當抬起腳離開中點（落地），或是身體嚴重失去平衡，即判定「蛋破」並停錶。
5. **結算常模**：根據台灣體育署與醫學界成人常模，自動結算分數並給予端午專屬趣味稱號。

---

## 🛠️ 技術棧與套件

- **前端架構**：純 HTML5 / CSS3 / JavaScript (ES6+)
- **AI 視覺辨識**：[Google MediaPipe Pose](https://google.github.io/mediapipe/solutions/pose.html) (經由 CDN 引入)
- **硬體需求**：一般筆電 WebCam 視訊鏡頭、流暢的網路連線
