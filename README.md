🌿 沉浸式立蛋挑戰 (AI 防跌平衡遊戲)
「沉浸式立蛋挑戰」 是一款結合 AI 電腦視覺與前端互動技術的單足立平衡遊戲。
無需下載任何 APP，只要開啟網頁並授權鏡頭，就能透過趣味的「立蛋」意象，進行核心肌群與平衡感的自我挑戰。本作特別適合一般大眾與長者作為「防跌倒」的居家趣味訓練。

✨ 核心特色
🤖 AI 零延遲骨架捕捉
採用 Google MediaPipe Pose 模型，即時且輕量地捕捉全身 33 個 3D 關節點，不需高階設備即可在手機瀏覽器順暢運行。

🛡️ 高精準防誤判系統 (Anti-Cheat)

真實軀幹傾斜演算法：以「雙肩連線中心」與「雙臀連線中心」計算真實的物理傾斜角。揮手、搖頭等動作皆不會干擾判定。

動態比例尺：系統會自動抓取玩家的「小腿長度」作為動態判斷基準，精準偵測抬腳與滑落，無視玩家站立距離遠近。

動態歸零校正：抬腳觸發計時的瞬間，系統會記錄當下的身體角度作為「基準 0 度」，確保每個人開局都能在完美的正中央。

🌪️ 沉浸式干擾與聲光特效

利用純 CSS 打造多層次「陣風風切視覺」與「碎裂、爆漿、地震」特效。

內建 Web Audio API 即時合成環境風切聲、計時滴答聲與破裂音效（無外部音檔連結失效風險）。

🔒 絕對的隱私安全
本遊戲為 100% 純前端 (Client-Side) 運算，相機畫面僅在本地瀏覽器的記憶體中進行 AI 分析，絕對不會錄影、儲存或上傳任何影像資料。

🎮 遊玩方式
進入遊戲：閱讀安全聲明與動作圖解後，授權網頁使用相機鏡頭。

第一階段 (定位)：將手機/筆電放置穩固，退後直到頭部、雙膝蓋、雙腳踝完整入鏡。

第二階段 (觸發)：畫面小腿處會出現「金色光圈」。任選一隻腳抬起，將腳踝貼近支撐腳的小腿即可觸發「天亮」並開始計時。

保持平衡：

畫面的「巨蛋」會連動你的身體傾斜。

撐滿 30 秒 即可獲得滿分稱號與灑花慶祝！🎉

⚠️ 失敗條件：若身體傾斜角度過大碰到邊緣，或是抬起的腳滑落離開小腿，巨蛋將會當場爆裂！

🛠️ 技術棧 (Tech Stack)
HTML5 / CSS3 (純手工刻製的特效與響應式 RWD 介面)

Vanilla JavaScript (無依賴 React/Vue 等框架，追求極致輕量化)

MediaPipe Pose (Google 開源機器學習視覺庫)

Web Audio API (環境音效合成)
